# Oworks Marketing Tech Website

## Scope
Replace the portfolio template’s demo content with Oworks Marketing Tech Pvt Ltd’s agency content while retaining the existing visual system, spacing, transitions, and interaction style.

## Pages and navigation
- Update the shared header and footer with the Oworks brand, requested navigation, contact details, social placeholders, and footer links.
- Build routes for Home, About, Services, dynamic Service details, Industries, dynamic Industry details, Contact, Blog, dynamic Blog post detail, and a friendly missing-page fallback.

## Content and reusable building blocks
- Store the 16 services, four industries, and placeholder posts in data modules.
- Create shared placeholder-image, contact-form, and closing-call-to-action blocks so content stays consistent and easy to replace later.
- Use clearly labelled neutral placeholder blocks/images and descriptive replacement alt text throughout.

## Page content
- Populate Home, About, Services, Industries, Contact, and Blog with the supplied copy.
- Use one data-driven service-detail template and one data-driven industry-detail template, including the requested special layouts for Strategy Development and Merchandise.
- Make every supplied internal link resolve and send both contact calls-to-action to the on-site form, with “Work with Us” pre-selected.

## Technical details
- Preserve the existing React, Tailwind, typography, palette, and scroll-reveal patterns.
- Set site metadata for Oworks in the static document and use route-aware document titles/descriptions for in-app navigation.
- Validate the rebuilt routes and contact-form success state in the preview.
